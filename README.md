# טיול במזרח — משחק ללימוד Flexbox

משחק דפדפן ללימוד ותרגול של Flexbox. בכל שלב טסים ליעד אחר במזרח אסיה, ומסדרים את
המטוסים על הלוח באמצעות מאפייני Flexbox עד שהם מגיעים לסידור המבוקש. הטיול נפתח ביפן
ומסתיים בנחיתה בישראל.

נבנה ב‑HTML, CSS ו‑JavaScript בלבד, ללא ספריות חיצוניות וללא CSS Grid.

## הפעלה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

## מבנה הפרויקט

```
index.html          מבנה העמוד
css/style.css       עיצוב האתר ומבנה ה‑Flexbox
js/levels.js        נתוני השלבים: יעדים, תפאורות, פקדים ופתרונות
js/game.js          לוגיקת המשחק: פקדים, בדיקה, ניקוד וניווט
```

## השלבים

| # | יעד | מאפיינים בשלב | הפתרון |
|---|-----|----------------|--------|
| 1 | יפן, טוקיו | `display` | `display: flex` |
| 2 | וייטנאם, מפרץ הא לונג | `display`, `justify-content` | `flex` + `flex-end` |
| 3 | לאוס, לואנג פראבנג | `flex-direction`, `align-items` | `column` + `center` |
| 4 | תאילנד, פוקט | `justify-content`, `align-items` | `space-between` + `flex-end` |
| 5 | קמבודיה, אנגקור ואט | `flex-direction`, `justify-content`, `align-items` | `row-reverse` + `center` + `center` |
| 6 | הפיליפינים, פלאוואן | `flex-wrap`, `justify-content`, `align-content` | `wrap` + `center` + `center` |
| 7 | דרום קוריאה, סיאול | `flex-direction`, `justify-content`, `align-items` | `column-reverse` + `flex-start` + `flex-end` |
| 8 | נפאל, קטמנדו | `flex-direction`, `flex-wrap`, `justify-content`, `align-content` | `column` + `wrap` + `center` + `center` |
| 9 | ישראל, נתב״ג | `flex-direction`, `flex-wrap`, `justify-content`, `align-content` | `row` + `wrap` + `space-around` + `space-between` |

שמונה מתוך תשעת השלבים דורשים שילוב של יותר ממאפיין אחד, ושלושה שלבים בנויים סביב `flex-wrap`.
אין שני שלבים עם אותו פתרון, ואין זוג שלבים שנבדל רק בערך בודד.

## מה המשחק כולל

- מחוון שלב נוכחי, ניקוד מצטבר וספירת ניסיונות.
- בדיקת פתרון עם הודעת הצלחה או הודעת שגיאה שמצביעה על המאפיינים שעדיין לא במקום.
- איפוס השלב הנוכחי לערכי ברירת המחדל.
- תצוגת קוד חיה של סגנונות הלוח, שמתעדכנת עם כל בחירה.
- הצגת היעד: מתאר מקווקו של הסידור המבוקש (מוריד נקודות).
- רמז לכל שלב (מוריד נקודות).
- שמירת התקדמות בדפדפן וחזרה חופשית לשלבים שהושלמו.
- מסך סיום עם פירוט הניקוד בכל יעד.

## הערות מימוש

- לוח המשחק הוא `480×400` פיקסלים בכל גודל מסך. במסכים צרים הוא מוקטן חזותית בלבד
  באמצעות `transform: scale`, כך שסידור ה‑Flexbox — ולכן הפתרון לכל שלב — נשאר זהה
  בכל רזולוציה.
- העמוד כולו RTL, ואילו לוח המשחק מוגדר `dir="ltr"` כדי ש‑`flex-start` יהיה תמיד צד שמאל
  ו‑`flex-end` תמיד צד ימין, בהתאם להוראות השלבים.
- שכבת "היעד" נבנית מאותם הפריטים ובאותן המידות כמו הלוח, עם סגנונות הפתרון,
  ולכן היא תמיד תואמת במדויק לפתרון שהוגדר לשלב.
- התפאורות של כל מדינה מצוירות ב‑SVG וב‑CSS, ללא קבצי תמונה חיצוניים.
